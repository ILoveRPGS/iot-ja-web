# iot-ja-web

Web course exercises (HTML, CSS, JavaScript).

## Weather station (week11)

`week11/scripts.js` reads a WeatherAPI.com key from the constant `API_KEY`.
The committed value is the placeholder `YOUR_WEATHERAPI_KEY`, so the page
shows no weather data until you replace it locally with your own key from
https://www.weatherapi.com/. Do not commit a real key. Keys that were
committed earlier remain in git history and must be revoked.
